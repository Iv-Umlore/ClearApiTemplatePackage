# Base Description

*Данный проект реализован по программе [курса](https://stepik.org/course/249828)*

*Тот же проект, но в готовом виде и со всеми пояснениями можно найти [тут](https://github.com/iksergey/dotnet-clean-architecture-template)*

Это шаблон для создания проекта с нуля, для быстрого разворачивания новых апи с "чистой архитектурой"

Чтобы опубликовать новую версию с помощью Github Actions необходимо сменить версию в Template.csproj и запушить новый tag вида v*.*

## Version 1.1.0

На текущий момент версия завершена на 90%, происходит публикация полноценного шаблона

Шаблон сохраняет совю структуру и все необходимые файлы так же находяться в проекте при создании из шаблона
